# v172.2 — Cross-platform locality source evidence review

Source review now offers guarded HTTPS original-post links, distinct-platform
inventories, and timestamp comparison within 72 hours of the selected source.
These are investigative review leads only. Cross-platform repetition, shared
localities and temporal proximity do not establish independent corroboration
or that sources describe a single incident.

The server rejects unsafe external URLs and timezone-naive publication dates
rather than fabricating evidence; the existing campaign and source-level ACLs
remain in place. No provider calls, schema migrations, officer decisions or
existing records are changed. Regression tests cover unsafe URLs, incomplete
timestamps, cross-platform summaries and temporal uncertainty.
