# v102.4 Radar feed fail-closed and single-campaign default

If the officer has exactly one authorized Inbox campaign and has not selected a campaign, Radar automatically chooses it. When a selected Inbox campaign feed fails, the page now displays the error without silently substituting the unrelated historical pilot. The officer may explicitly choose the Historic Radar pilot view. This reduces accidental misinterpretation of unrelated sources and supports actual Inbox-first workflows. Multiple campaigns still require explicit choice. No paid AI usage.
