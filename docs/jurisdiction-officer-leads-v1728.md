# v172.8 — Actionable, read-only jurisdiction officer review leads

The v172.7 campaign readiness sample now includes up to twelve authorized
source references awaiting human incident-locality investigation. Priority
order is stale/conflicted decisions, multiple incident-locality candidates,
single explicit locality, and cases missing a specific city cue.

The existing Inbox can focus an item if it appears on the currently loaded
page. Other references remain discoverable through the normal campaign Inbox;
an external source link is rendered only when its saved URL passes HTTPS
validation. No user-triggered provider work, classification changes or
geographic access expansion is introduced.

The output is capped to the most recent 30 campaign evidence links and is
not a comprehensive client-acceptance queue. A real officer must inspect the
original source and record each human decision; no inferred city is
automatically promoted into an approved incident jurisdiction.
