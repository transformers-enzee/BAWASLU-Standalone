# v155.3: Saved-source pilot evidence readiness

The permission-scoped pilot shortlist now separates missing saved original text, missing original URL, and both missing. Counts explicitly cover only the authorized saved Inbox window. Existing active cases are counted only among the displayed preview (max 12) and are never misreported as a full-population count. An already-existing case may still be opened for human re-review, even if source evidence is incomplete; neither availability nor opening that case authenticates its source.

The bilingual officer screen displays the exact recovery requirement for each source plus missing-text, missing-URL and preview-existing counts. All evidence remains preliminary. The underlying source access, jurisdiction authorization and casework creation checks are unchanged. No live casework, paid crawl, AI call or database migration is performed.
