# v172.0 — Source-grounded Kabupaten/Kota incident candidates

## Scope delivered
- Reuse the bundled 514-regency reference registry to recognize explicit
  incident-locality constructions such as "dugaan pelanggaran terjadi di Kota Bandung".
- Surface candidate names, province and exact source phrase in the authorized
  Intelligence Inbox incident jurisdiction preview.
- Aggregate one or multiple candidate regencies into the existing unverified
  province-cue list, without using account profile or the campaign assignment.
- Mark contradictory provinces and multiple regencies as ambiguous in the UI.
- Preserve existing human province confirmation rules; the new city candidates
  **cannot be confirmed or used for access policy** by this build.
- Cover source-context/no-context, cross-province ambiguity, and no-credit boundaries.
