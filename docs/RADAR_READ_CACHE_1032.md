# v103.2 low-cost Smart Radar fetch caching

Approved V6.2 UI unchanged. The live adapter now deduplicates concurrent GETs and memoizes short-lived dashboard (30s), evidence finding (60s) and officer history (10s) responses. Cache is memory-only, bounded to 80 entries, cleared when access token changes or when an authenticated mutation is submitted, and failed requests evict immediately. Browser fetch still uses no-store, so data is not stored in a persistent HTTP cache or shared across logins. Server already caches source rows (600s default), AI rows, topics, geography separately; this is an extra request-reduction layer. Stale officer actions always use network. This does not reduce the database cost of distinct requests or guarantee cross-instance cache hits. Continue #12/#13/#14 separately.
