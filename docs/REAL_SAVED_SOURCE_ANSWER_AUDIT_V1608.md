# v160.8 — permission-scoped actual saved-source answer audit

The Assistant's existing evaluation sampler prepares questions from permission-scoped, cached Intelligence Inbox findings but does not generate or evaluate actual answers. This release provides a manual answer-audit handoff: choose a prepared real source, run its question in the Assistant explicitly, paste the response into the review panel and check citation/readiness against the current saved source text. Paid inference is never triggered by the audit.

The POST /api/assistant-evaluation/saved-answer-audit endpoint is **read-only** despite POST transport. It requires an authenticated profile with view_intelligence permission; reuses live_inbox_findings(db,principal) so province and campaign access are enforced upstream; requires all supplied source IDs to match current authorized saved relevant posts with nonempty original text; de-duplicates source links; rejects nonexistent, forged and conflicting source versions. Neither source excerpts nor pasted answer are returned, logged by this code, written to the database, or placed in exports. Responses are cache-disabled.

The output contains source IDs, displayed citation IDs, unauthorized citation count, and minimal deterministic readiness checks. It does not verify the pasted text came from a particular model run, prove its claims, assess legal authority, calculate human accuracy or grant BAWASLU acceptance. Human review of factual truth is still essential. Pilot cases are sourced only from the user's current authorized Inbox window; no claims of complete population coverage or fixed new source counts. QA tests use isolated fixtures, not production writes.
