# 101.6: actual Inbox-based Radar perspective

When Smart Radar opens with an authorized campaign_id, the default live view now shows summary counts of latest saved Inbox topics and preliminary concern/issue signals, with source drilldowns. The officer can explicitly switch back to the preserved historical pilot view. Without a selected campaign, the pilot remains the existing default.

All counts reflect campaign-authorized saved Inbox data. They do not imply verified incidents, public sentiment sampling, or a historical pilot ID crosswalk. This implements a functional frontend read experience but does not claim complete Radar feature parity or close #13.

No provider calls. Officer correction panel unchanged.
