# Build v107.0 — Shared potential-violation contract and difficult-case QA

Latest saved quote-validated assessment and latest officer review drive one
shared provisional flag decision. Inbox, Watchlist own posts and campaign-earned
mentions, and the campaign Command Centre use the same helper. Smart Radar
displays campaign flags in a clearly separate section from older pilot sources;
source IDs are not joined without verified lineage.

Keyword-only phrase review leads do not become saved-flag indicators.
Officer dismissal suppresses a flag without destroying evidence.
Uncertainty is explicit and human review never implies a legal ruling.

Deterministic regression examples include supported/unsupported citations,
inactive categories, malformed signals, informational keyword mentions,
officer dismissals, escalations and historical reports.

This is NOT a claim of AI classification accuracy. The larger pre-feed requires
actual successful assessed runs against analyst-approved reference labels.
Authenticated paid inference must be explicitly cost-confirmed and budgeted;
deployment and automated unit tests do not trigger paid requests.
