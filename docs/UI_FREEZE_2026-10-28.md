## Existing application integration baseline

- FastAPI backend with existing auth, role permissions, location ACL, source collection, AI triage, QA and Smart Radar endpoints.
- Render deployment targets main. This branch is for review and is not automatically deployed until merged.

## Source lineage contract (to validate before data cutover)
- Source post ID: stable provider/source identifier; for imports store original ID and canonical internal ID distinctly.
- Candidate ID: registry identity, not display name or alias; aliases resolve to an existing candidate.
- Findings and reviews refer back to source posts through explicit associations; never infer wrongdoing from a mention.
- Watchlist activation is independent of investigation status; stopping tracking must preserve posts, findings and audit history.
- Always retain source URL, platform, published time, account provenance and original content. Distinguish absent data from verified values.
